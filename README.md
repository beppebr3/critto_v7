Its core purpose is to provide a flexible keyboard injection system that supports both USB and Bluetooth Low Energy (BLE) HID output,
while also integrating a lightweight encryption workflow for secure text transmission. 

In practical terms, the device can act as a programmable keyboard emulator, generate and manage secret keys, select keyboard layouts,
and send data either in plain text or in encrypted, base64-formatted form.

The firmware is intended for controlled, professional use cases where a compact device must emulate keyboard input, send commands, 
and optionally protect sensitive messages using symmetric encryption. 
It combines hardware input, display-driven navigation, HID emulation, persistent storage, and user-selected keyboard mapping into a single interface.
